# Astria 1.13.2 — a crashed game page no longer stops Astria

## English

- Fixed the "A JavaScript error occurred in the main process — Render frame was disposed before WebFrameMain could be accessed" error. It appeared when a game page's process ended (a crash or a reload) and left Astria unresponsive.
- Astria now keeps running when that happens. The account shows why its page ended and can be reloaded; the frame-rate limit is applied again when the page is back.

Update using **Menu → Check for updates**.

## Português (Brasil)

- Corrigido o erro "A JavaScript error occurred in the main process — Render frame was disposed before WebFrameMain could be accessed". Ele aparecia quando o processo da página de um jogo encerrava (uma falha ou um recarregamento) e deixava o Astria travado.
- Agora o Astria continua funcionando quando isso acontece. A conta mostra por que a página encerrou e pode ser recarregada; o limite de FPS é aplicado de novo quando a página volta.

Atualize em **Menu → Verificar atualizações**.
