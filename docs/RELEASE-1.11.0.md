# Astria 1.11.0 — Account order and extensions

## English

- Drag accounts up or down in the sidebar. **Move up** and **Move down** are also available in the account menu. The order is saved per workspace.
- Use the puzzle button beside **Performance** or **Extensions…** in the account menu. Install an unpacked folder containing `manifest.json`, then reload the account to apply its page scripts.
- Open an extension's panel, enable, disable or remove it separately for each account. Extension copies stay in **Save/Extensions** and their data stays in the account profile.
- Supports a subset of Chrome APIs, including tested content scripts, extension workers, panel UI and account-scoped macro input. Chrome Store installation and `.crx` packages are unavailable.

Update using **Menu → Check for updates**.

## Português (Brasil)

- Arraste as contas para cima ou para baixo na lateral. **Mover para cima** e **Mover para baixo** também estão no menu da conta. A ordem é salva por espaço.
- Use o botão de quebra-cabeça ao lado de **Desempenho** ou **Extensões…** no menu da conta. Instale a pasta descompactada que contém `manifest.json` e recarregue a conta para aplicar os scripts.
- Abra o painel, ative, desative ou remova extensões separadamente por conta. As cópias ficam em **Save/Extensions** e os dados ficam no perfil da conta.
- O suporte às APIs do Chrome é parcial. Os testes cobrem scripts, processos de extensões, painel e macros restritos à conta. A loja do Chrome e pacotes `.crx` não estão disponíveis.

Atualize em **Menu → Verificar atualizações**.
