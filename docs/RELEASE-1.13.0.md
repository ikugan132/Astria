# Astria 1.13.0 — Extensions inside the game window

## English

- Extension pages now open inside the account's game panel, on the right side, instead of in a separate window.
- A new rail on the right edge of the window lists the selected account's extensions. Click one to open it beside the game. Click it again to hide it; the extension keeps running, so a macro is not interrupted.
- Several extensions can stay open per account. Switch between them from the rail; a dot marks the open ones.
- Drag the divider between the game and the extension to change its width. Each extension remembers its width.
- The extension header has buttons to open it in its own window, as before, or to close it.
- When an extension page closes itself (for example AutoSell after "Mark"), the panel only hides, so you can click in the game.

Update using **Menu → Check for updates**.

## Português (Brasil)

- As páginas das extensões agora abrem dentro do painel do jogo da conta, no lado direito, em vez de numa janela separada.
- Uma nova barra na borda direita da janela lista as extensões da conta selecionada. Clique numa para abri-la ao lado do jogo. Clique de novo para escondê-la; a extensão continua rodando, então um macro não é interrompido.
- Várias extensões podem ficar abertas na mesma conta. Troque entre elas pela barra; um ponto marca as que estão abertas.
- Arraste a divisória entre o jogo e a extensão para mudar a largura. Cada extensão lembra a sua largura.
- O cabeçalho da extensão tem botões para abri-la numa janela separada, como antes, ou para fechá-la.
- Quando a página de uma extensão se fecha sozinha (por exemplo, o AutoSell depois de "Marcar"), o painel só se esconde, para você clicar no jogo.

Atualize em **Menu → Verificar atualizações**.
