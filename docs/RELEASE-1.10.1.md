# Astria 1.10.1 — Subtle Auto Clicker circles

## English

- Auto Clicker markers are now simple circles at 50% opacity, without crosshair lines, target names or countdown text.
- Choose each point's color in the Auto Clicker editor. Red is the default for new and existing points.
- Turn off **Show circle** and press **Start targets** to keep the actions running without a marker. Explicit **Preview marker** still briefly shows the chosen point and color.
- Marker preferences stay with each account in **Save/Automation**. Existing targets, intervals and actions are preserved.
- Static markers no longer refresh four times per second to update countdown text.
- Restoring Floating now ignores late layout rectangles from the previous main account, preserving the chosen floating accounts.

Update using **Menu → Check for updates**. Preserve **Save** when updating manually.

## Português (Brasil)

- Os marcadores do Auto Clicker agora são círculos simples com 50% de opacidade, sem traços de mira, nomes ou contagem.
- Escolha a cor de cada ponto no editor do Auto Clicker. Vermelho é o padrão para pontos novos e existentes.
- Desative **Mostrar círculo** e pressione **Iniciar alvos** para manter as ações funcionando sem marca. **Ver marcador** continua mostrando uma prévia breve do ponto e da cor escolhida.
- As preferências ficam por conta em **Save/Automation**. Pontos, intervalos e ações existentes são preservados.
- Os círculos estáticos não precisam mais atualizar quatro vezes por segundo para mostrar uma contagem.
- Restaurar o layout Flutuante ignora posições atrasadas da conta principal anterior, preservando as contas flutuantes escolhidas.

Atualize em **Menu → Verificar atualizações**. Preserve **Save** na atualização manual.
