# Astria 1.10.2 — Continuous background automation

## English

- Running automation keeps its account loaded when hidden. The five-minute **Active when visible** idle timeout no longer unloads a page that is still sending actions.
- Automation also keeps background timers unthrottled when Astria is minimized. Switching accounts or workspaces does not stop it.
- Press **Stop** to end the actions and restore the account's normal activity policy. Eco rendering limits remain in effect.
- Explicit suspension, closing, navigating the page or starting the other automation tool still ends the current run. No actions start automatically after restarting Astria.
- Existing settings, marker colors, sessions and the portable **Save** folder are preserved.

Update using **Menu → Check for updates**.

## Português (Brasil)

- Uma automação em execução mantém a conta carregada quando oculta. O prazo de cinco minutos do modo **Ativa quando visível** não descarrega mais uma página que ainda envia ações.
- Os temporizadores da automação continuam ativos mesmo com o Astria minimizado. Trocar de conta ou de espaço não encerra a execução.
- Pressione **Parar** para encerrar as ações e restaurar o modo de atividade normal da conta. Os limites de FPS do modo Eco continuam valendo.
- Suspender, fechar, navegar a página ou iniciar a outra ferramenta de automação continua encerrando a execução atual. Nada inicia sozinho ao reabrir o Astria.
- Configurações existentes, cores, sessões e a pasta portátil **Save** são preservadas.

Atualize em **Menu → Verificar atualizações**.
