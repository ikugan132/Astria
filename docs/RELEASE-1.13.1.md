# Astria 1.13.1 — Auto Clicker works alongside extensions

## English

- The Auto Clicker now runs while extensions control the same game (for example AutoSell or a macro extension). Before, it stopped with "This account already has an attached debugger."
- The Auto Clicker, every extension and **Clean unused memory** now share the game's one debugger connection. One of them stopping no longer disconnects the others.
- When two tools click at the same time, each click (press and release) now finishes before the next tool's click starts, so clicks are no longer lost. Keys are not delayed.
- A debugger opened by another program (such as DevTools) is still respected and never taken over.

Update using **Menu → Check for updates**.

## Português (Brasil)

- O Auto Clicker agora funciona enquanto extensões controlam o mesmo jogo (por exemplo, o AutoSell ou uma extensão de macro). Antes, ele parava com "This account already has an attached debugger."
- O Auto Clicker, todas as extensões e o **Limpar memória sem uso** agora dividem a única conexão de debugger do jogo. Quando um deles para, os outros continuam conectados.
- Quando duas ferramentas clicam ao mesmo tempo, cada clique (apertar e soltar) termina antes de o clique da outra começar, então nenhum clique se perde. As teclas não sofrem atraso.
- Um debugger aberto por outro programa (como o DevTools) continua sendo respeitado e nunca é tomado.

Atualize em **Menu → Verificar atualizações**.
