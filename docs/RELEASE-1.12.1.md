# Astria 1.12.1 — Extensions share the game tab

## English

- Several extensions in one account can now control the same game tab at the same time, as in Chrome. Before, a second extension (for example a macro extension while an auto-seller was on) failed with "This account tab already has an attached debugger."
- When an extension tries to take a tab that it, or Astria's Auto Clicker, already controls, the error now uses Chrome's wording, so extensions that retry on that error recover by themselves.

Update using **Menu → Check for updates**.

## Português (Brasil)

- Várias extensões da mesma conta agora podem controlar a mesma aba do jogo ao mesmo tempo, como no Chrome. Antes, a segunda extensão (por exemplo, uma de macro com um auto-vendedor ligado) falhava com "This account tab already has an attached debugger."
- Quando uma extensão tenta controlar uma aba que ela mesma ou o Auto Clicker do Astria já controla, o erro agora usa a mensagem do Chrome. Assim, as extensões que tentam de novo quando recebem esse erro se recuperam sozinhas.

Atualize em **Menu → Verificar atualizações**.
